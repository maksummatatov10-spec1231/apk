# Джанкил — фан-битва (Android, Java)

Фан-игра по персонажу **Джанкил** из мода *Deltarune: Chapter Rewritten* (не канон Deltarune).

## Механика
- **Сигнал Морзе** перед каждым ходом: нужно выбрать переданное слово (SOS, JUNK, FREE, BUY, SALE, HELP, YES, NO).
  Верно: Довольство +25, следующая атака слабее. Неверно: Довольство −10, следующая атака сильнее.
- **ДЕЙСТВИЕ**: ОСМОТРЕТЬ, СИГНАЛ, ТОРГОВАТЬСЯ (+15 Довольства, +батарейка, атака сильнее).
- **БОЙ**: тайминг-полоска, точный удар — до 12 урона. ХП Джанкила (90) меняется сразу.
- **АРЕНА**: джойстик, уворот от падающего хлама, сигнал Морзе летит поверх; каждое попадание — −2 ХП игроку (20).
- **МИЛОСТЬ** открывается при Довольстве 100 — мирный конец.

## Структура
- `src/com/example/junkil/` — `BattleLogic` (правила, без Android), `ArenaSim` (арена), `MorseCode`, `Phrases` (все реплики, русский), `BattleView` (экран), `MainActivity`.
- `res/drawable-nodpi/` — спрайты (нормальный, злой, грустный); исходники в `build-src/`.
- `test/` — JVM-тесты логики и UI-харнесс (заглушки Android).
- `docs/screens/` — снимки экранов.

## Команды
```
scripts/test.sh          # логика (63 проверки)
scripts/ui-test.sh       # интерфейс через касания (36 проверок)
scripts/screenshots.sh   # снимки docs/screens/
tools/build-app.sh junkil-battle Junkil-v1.0.apk   # из корня репозитория
```
