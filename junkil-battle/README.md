# Джанкил — фан-битва (Android, Java, landscape)

Фан-игра по персонажу **Джанкил** из мода *Deltarune: Chapter Rewritten* (не канон Deltarune).
Версия 2.0. Ориентация — альбомная. Интерфейс и речь — на русском.

## Управление
- **Джойстик слева** (крупный): двигает выбор в меню и сердце на арене.
- **Z** — подтвердить. **X** — назад. **C** — инвентарь (батарейки).
- Меню и подменю работают джойстиком; сердце-курсор выбирает пункт, как в Undertale.
- Управление работает и вне боя (на экранах меню, пауза, финал).

## Механика
- **БОЙ**: тайминг-полоска (Z останавливает), точный удар — до 12 урона. ХП Джанкила (90) уменьшается **сразу** при ударе.
- **ДЕЙСТВИЕ**: ОСМОТРЕТЬ, СИГНАЛ (расшифровка Морзе), ТОРГОВАТЬСЯ (+15 Довольства, атака сильнее).
- **АРЕНА** (квадратная во время атаки, прямоугольная в остальное время):
  - Ход начинается с **ЧАСТОТЫ** (Морзе из выбранного слова): каждая точка — колючка, летящая в сердце; тире — стена с проёмом под сердце.
  - Затем две случайные атаки из: **ПРИЦЕЛ** (фигуры летят в сердце), **СТЕНА** (проём под сердце), **КАРУСЕЛЬ** (кольцо с проходом к сердцу), **ОТСКОК** (монеты с отскоком от стенок арены).
  - **ТЁМНЫЙ БАК** (фирменная атака, только финал): перед геноцидом (ХП Джанкила 0) и перед милостью (Довольство 100) Джанкил выпускает этот залп. Крышка бака сходится, арена темнеет, видно только круг света вокруг сердца. Джанкил произносит реплику «ТЫ ЧТО ДЕЛАЕШЬ В МОЁМ БАКЕ?!» (субтитры справа от арены, звук `junkil_bak`). Крышка бака с ручками. Перед каждым из двух залпов по три выстрела жёлтый пунктир показывает, куда полетит фигура; через 1.5 с выстрел летит по нему. Двигайтесь с линии. В обычных ходах не выпадает.
  - Белые пули — бесшовные текстуры атак (10 вариантов), с неправильными контурами, не прямоугольники.
  - Каждое попадание — −2 ХП игроку (20). ХП 0 — поражение.
- **СИГНАЛ Морзе** в меню: верно — Довольство +25, следующая атака слабее; неверно — Довольство −10, атака сильнее.
- **МИЛОСТЬ** открывается при Довольстве 100 — мирный конец.
- Звуки: выбор, подтверждение, удар, урон, лечение, милость, свист атаки, скрип крышки и блик подсказки «Тёмного бака», победа/поражение, морзе-тон для каждого слова.

## Структура
- `src/com/example/junkil/` — `BattleLogic` (правила, без Android), `ArenaSim` (арена: расписание атак, `currentAttack()`), `MorseCode`, `Phrases` (реплики, русский), `BattleView` (экран), `Sounds` / `AndroidSounds` (звуки через `SoundPool`), `MainActivity`.
- `res/drawable-nodpi/` — `junkil.png` (спрайт 290×440) и `atk_*.png` (10 бесшовных текстур 512×512 — 9 файлов тут, см. `build-src/`).
- `res/raw/` — 18 WAV-звуков (22050 Гц, моно): `make_sounds.py` в `build-src/`.
- `build-src/` — исходники спрайта и текстур (`process_v2.py`), генератор звуков.
- `test/` — JVM-тесты логики и UI-харнесс (заглушки Android, запись звуков `RecSounds`).
- `docs/screens/` — снимки экранов (landscape).
