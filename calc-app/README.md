# Калькулятор и решатель — Android 12+

Приложение для Android (minSdk 21, target **Android 12 / API 31**), интерфейс на русском.
Оформление — Material You: цвета берутся из системной палитры на Android 12+, есть светлая и тёмная темы.

## Возможности

- **Вычисления с пошаговым решением**: `(2 + 3) · 4 ÷ 5 − 2³` → каждый шаг свёртки.
- **Уравнения с одной переменной x**:
  - линейные: `3x − 4 = 2x + 5`;
  - квадратные: дискриминант, точные корни, комплексные корни (`x² + 4x + 13 = 0`);
  - многочлены 3-й и 4-й степени: подбор рациональных корней (теорема о рациональном корне), деление многочлена на `(x − r)`, затем квадратное уравнение; если рациональных корней нет — численно (метод Дюрана–Кернера);
  - нелинейные (`sin(x) = 0,5`, `√(x + 4) = 3`): сканирование смены знака и бисекция.
- **Системы линейных уравнений** (до 3 переменных x, y, z) — через `;` или с новой строки, метод Крамера с определителями по шагам.
- **График** функции с осями, сеткой и отмеченными корнями.
- Математическая клавиатура внизу экрана, три страницы (вкладки):
  - **Цифры**: цифры, `+ − × ÷`, скобки, `x`, `y`, `^`, `%`, `!`;
  - **Функции**: `sin cos tan asin acos atan ln log √ ∛ |x| π e`, `x² x³ xⁿ eˣ 10ˣ`, `n!`, `1/x`, пара `()` (курсор ставится внутрь);
  - **Символы**: переменные `x y z a b c k m n t`, степени `² ³ ⁴`, `·`, `;` для систем.
  - Кнопка «AC» очищает ввод, «⌫» удаляет символ, «=» решает.
- Левое меню (кнопка ☰ в углу или свайп от левого края): **Калькулятор**, **Уравнения** (по темам: линейные,
  квадратные, степенные, системы, иррациональные, тригонометрические), **Примеры** (арифметика, корни,
  тригонометрия и логарифмы, графики), **История** (сохраняется между запусками), **Справка**.
  Нажатие на пример открывает калькулятор и сразу решает его.
- Нажмите на ответ, чтобы скопировать его в буфер обмена.
- Ввод: `2x²` или `2x^2`, `x⁴`, `3π`, `(x+1)(x−1)`, десятичная запятая `2,5` и точка `2.5`.
  Системная клавиатура не выезжает: ввод идёт через встроенную клавиатуру (физическая клавиатура тоже работает).

## Интерфейс

- Кнопка «☰» слева вверху открывает левое меню, сгруппированное по разделам: «Решение» (Калькулятор, Уравнения), «Примеры» (Числа, Степени, Корни, Тригонометрия, Логарифмы, Графики), «Прочее» (История, Справка). Панель закрывается по кнопке, затемнению или свайпом.
- Нажатие на поле ввода открывает математическую клавиатуру вместо системной. Клавиатуру можно свернуть: ручкой «Свернуть», кнопкой с иконкой клавиатуры или «Назад».
- Клавиша «=» вставляет знак равенства. Решение запускается кнопкой «Решить» (на клавиатуре и под полем ввода).
- Запись графика: `sin(x)`, `x² − 2x` или `y = x^2 − 2x`, `f(x) = cos(x)`.
- Степени раскрываются пошагово: `9^9` → `9·9 = 81` → `81·9 = 729` → … → `387420489`.

## Лаборатория решателя (`lab/`)

Веб-страница для проверки решателя: тот же Java-код решает уравнение, а `lab/verify.py` сверяет ответы с независимым решателем (sympy, numpy).

```
bash scripts/build-cli.sh                 # собрать CLI-обёртку решателя
python3 lab/server.py 8000                # открыть http://localhost:8000
/tmp/venv/bin/python lab/verify.py -v     # сверка с sympy (нужны sympy, numpy, mpmath)
```

Сверка последнего запуска: 73 из 73 совпали, расхождений нет.

## Сборка

Нужен тулчейн без Android Studio (ставится из PyPI/npm/GitHub, см. `tools/`):

```bash
../tools/setup-toolchain.sh   # один раз
./scripts/test-math.sh        # проверка математики
./scripts/build-calc.sh       # -> build/calc.apk
```

Готовый APK: `dist/CalcSolver-v1.0-debug.apk`.

## Важные ограничения

- Сборка сделана **без Gradle и Android SDK**: aapt2, javac 8, D8 и android.jar из открытых источников.
  Результат проверен: ресурсы и манифест линкуются (`aapt2`), dex декомпилируется apktool, подпись проверяется,
  математическое ядро проходит 46 автоматических проверок на JVM.
- **Интерфейс не запускался на реальном устройстве или эмуляторе** — проверка на телефоне обязательна.
- Подпись — **debug-ключ, схемы v1 (JAR) и v2**. Схема v2 обязательна для установки на Android 11+
  при `targetSdk` ≥ 30 (здесь 31): APK, подписанный только v1, Android 12 отвергает с сообщением
  «пакет не действителен / повреждён». `tools/sign_apk.py` добавляет блок APK Signing Block (v2) и
  `X-Android-APK-Signed: 2` в CERT.SF. Проверка: `python3 tools/verify_apk.py <apk>`.
  Для публикации в Google Play нужен собственный ключ (и, при желании, схема v3).
- Иконка — простой векторный значок-заглушка.
- Анимации и жесты (панель, переходы экранов, появление карточек) написаны вручную под API 21 и не проверены на устройстве.
