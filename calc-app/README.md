# Калькулятор и решатель — Android 12+

Приложение для Android (minSdk 21, target **Android 12 / API 31**), интерфейс на русском.
Оформление — Material You: цвета берутся из системной палитры на Android 12+, есть светлая и тёмная темы.

## Возможности

- **Вычисления с пошаговым решением**: `(2 + 3) · 4 ÷ 5 − 2³` → каждый шаг свёртки.
- **Уравнения с одной переменной x**:
  - линейные: `3x − 4 = 2x + 5`;
  - квадратные: дискриминант, точные корни, комплексные корни (`x² + 4x + 13 = 0`);
  - многочлены 3-й и 4-й степени: подбор рациональных корней (теорема о рациональном корне), деление многочлена на `(x − r)`, затем квадратное уравнение; если рациональных корней нет — численно (метод Дюрана–Кернера);
  - нелинейные (`sin(x) = 0,5`, `√(x + 4) = 3`): сканирование смены знака и бисекция.
- **Системы линейных уравнений** (до 3 переменных x, y, z) — через `;` или с новой строки, метод Крамера с определителями по шагам.
- **График** функции с осями, сеткой и отмеченными корнями.
- Клавиатура с функциями (`sin cos tan ln log √ π e ! %`), история запросов, примеры на стартовом экране.
- Ввод: `2x²` или `2x^2`, `3π`, `(x+1)(x−1)`, десятичная запятая `2,5` и точка `2.5`.

## Структура

```
AndroidManifest.xml
res/                      ресурсы: макет, строки (RU), цвета (light/dark/Material You), темы, иконка
src/com/example/calcpro/
  MainActivity.java       экран, клавиатура, карточки решений, история
  GraphView.java          график функции (Canvas)
  math/Rational.java      точные дроби (BigInteger)
  math/Poly.java          многочлены с рациональными коэффициентами
  math/Node.java          дерево выражения: вычисление, точное значение, пошаговое упрощение, вывод
  math/Parser.java        разбор ввода (неявное умножение, степени, функции)
  math/Solver.java        решатель: выражения, уравнения, системы
  math/Functions.java     функции sin/cos/ln/sqrt/…
  math/Fmt.java           форматирование чисел для русского языка
test/.../SolverCheck.java  самопроверка математики (46 проверок)
scripts/build-calc.sh     сборка APK
scripts/test-math.sh      запуск самопроверки математики
```

## Сборка

Нужен тулчейн без Android Studio (ставится из PyPI/npm/GitHub, см. `tools/`):

```bash
../tools/setup-toolchain.sh   # один раз
./scripts/test-math.sh        # проверка математики
./scripts/build-calc.sh       # -> build/calc.apk
```

Готовый APK: `dist/CalcSolver-v1.0-debug.apk`.

## Важные ограничения

- Сборка сделана **без Gradle и Android SDK**: aapt2, javac 8, D8 и android.jar из открытых источников.
  Результат проверен: ресурсы и манифест линкуются (`aapt2`), dex декомпилируется apktool, подпись проверяется,
  математическое ядро проходит 46 автоматических проверок на JVM.
- **Интерфейс не запускался на реальном устройстве или эмуляторе** — проверка на телефоне обязательна.
- Подпись — **debug-ключ, схемы v1 (JAR) и v2**. Схема v2 обязательна для установки на Android 11+
  при `targetSdk` ≥ 30 (здесь 31): APK, подписанный только v1, Android 12 отвергает с сообщением
  «пакет не действителен / повреждён». `tools/sign_apk.py` добавляет блок APK Signing Block (v2) и
  `X-Android-APK-Signed: 2` в CERT.SF. Проверка: `python3 tools/verify_apk.py <apk>`.
  Для публикации в Google Play нужен собственный ключ (и, при желании, схема v3).
- Иконка — простой векторный значок-заглушка.
