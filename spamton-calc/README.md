# Спамтон — калькулятор с характером (Android 5+, target 12)

Калькулятор в стиле Deltarune. Спамтон считает, но постоянно врёт, печатает рекламу и
иногда захватывает телефон. Чтобы он начал считать точно, его надо победить в бою на
математических вопросах.

## Как играть

- **Калькулятор**: вводите выражение (`+ − × ÷ ^ %`, скобки, `√`), нажимаете `=`.
  До победы примерно 70% ответов Спамтона неверные. Верный ответ иногда выдаётся «по
  счастливой случайности».
- **Реклама**: бегущая строка сверху и всплывающие объявления на каждом втором вычислении.
  Кнопка «закрыть» три раза убегает, на четвёртый раз закрывает.
- **Захват**: после 5 вычислений Спамтон захватывает телефон (или удерживайте его портрет
  ~0.6 с). Начинается бой:
  - ход игрока: выберите правильный ответ на вопрос. Верный ответ бьёт Спамтона (8–16 урона,
    растёт с серией), неверный — лечит его на 4;
  - ход Спамтона: 6 секунд уклонения. Перетаскивайте красное сердце по арене, уворачиваясь от
    рекламных слов и купонов. Каждое попадание — 2 урона.
  - Спамтон: 60 HP. У игрока 20 HP. Проигрыш — новый раунд.
- **Победа**: Спамтон становится союзником, рекламы прекращаются, ответы точные, а в
  дисплее появляется метка «EXACT».

## Структура

```
AndroidManifest.xml, res/        манифест, строки, темы, иконка, звуки (res/raw/*.wav)
src/com/example/spamton/
  Calc.java          вычисление выражений (рекурсивный спуск), форматирование
  Spamton.java       искажение ответов, реплики, союзник
  Ads.java           тексты рекламы
  Battle.java        логика боя: вопросы, урон, фазы
  BulletField.java   поле пуль фазы уклонения (логические координаты)
  SpamtonSprite.java пиксельный Спамтон, рисуется процедурно (без чужих картинок)
  SpamtonView.java   весь экран: калькулятор, реклама, захват, бой (Canvas)
  MainActivity.java, AndroidSounds.java, Store.java, Sounds.java
test/com/example/spamton/LogicCheck.java  проверки логики (JVM)
test/harness/…                             сценарии касаний и скриншоты
test/stubs/android/…                       заглушки Android только для харнесса
scripts/gen_sounds.py    генерация звуков res/raw/*.wav
scripts/test.sh          проверки логики
scripts/ui-test.sh       проверки экрана: касания, реклама, бой, союзник
scripts/screenshots.sh   снимки в docs/screens/
scripts/render_ops.py    PNG из журнала команд харнесса (нужен Pillow)
```

## Сборка и проверки

```
tools/setup-toolchain.sh                      # один раз: тулчейн без Gradle
bash spamton-calc/scripts/test.sh             # логика: калькулятор, Спамтон, бой, пули
bash spamton-calc/scripts/ui-test.sh          # экран: касания, реклама, бой, союзник
bash spamton-calc/scripts/screenshots.sh      # скриншоты в docs/screens/
tools/build-app.sh spamton-calc Spamton-v1.0.apk   # результат: spamton-calc/build/Spamton-v1.0.apk
```

Скриншоты строятся из того же кода `SpamtonView`: заглушки Canvas пишут журнал команд,
а `render_ops.py` рисует PNG шрифтом DejaVu Sans Mono. Это не эмулятор Android: ширина
текста и сглаживание могут отличаться от реального устройства.
Python-окружение для Pillow: `python3 -m venv ~/.venv-render && ~/.venv-render/bin/pip install pillow`.

## Ограничения

- Проверено на JVM и по сборке APK. На реальном телефоне или в эмуляторе приложение не запускалось.
- Звуки сгенерированы синтезом (`scripts/gen_sounds.py`), не записаны актёром.
- Спрайт Спамтона нарисован процедурно, это не официальный арт Toby Fox.
