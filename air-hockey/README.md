# Air Hockey Challenge

Аэрохоккей на Android: стол, шайба, две ракетки, матч до 7 голов.

## Режимы

- **Против ИИ** — вы играете нижней ракеткой, ИИ верхней. Выбор уровня ИИ.
- **2 игрока** — одно устройство, каждый игрок касается своей половины стола.
- **Бот против бота** — два бота, у каждого свой уровень (например, Лёгкий против Мастера).

Уровни: Лёгкий, Средний, Сложный, Мастер (скорость ракетки, время реакции, точность).

Остальное: пауза, рестарт, меню, звук вкл/выкл, статистика матчей и три достижения
(первая победа, победа над Мастером, сухая победа 7:0), сохраняются на устройстве.

## Звуки

Синтезированы скриптом `scripts/gen_sounds.py` в `res/raw/*.wav`: удар, отскок, гол, подача,
клик, победа, поражение. Звуки ограничены мягким клиппингом и нормированы — громче и плотнее
прежней версии. Перегенерация: `python3 scripts/gen_sounds.py`.

## Сборка

```
tools/build-app.sh air-hockey AirHockey-v1.0.apk   # результат: air-hockey/build/AirHockey-v1.0.apk
```

Сборка без Gradle: aapt2 → javac 8 → D8 → подпись v1+v2 (debug-ключ). minSdk 21, targetSdk 31.

## Тесты

`scripts/test.sh` — физика и ИИ на JVM без устройства: стены, половины, туннелирование, предел скорости,
счёт до 7, гол в ворота, подача к проигравшему, матчи бот против бота (все пары уровней, 5 минут).

## Известные ограничения

- Шайба у боковой стенки может зажиматься между ракетками; против этого есть правило
  «25 секунд без гола — вбрасывание в центр». Полностью физику стенки это не решает.
- Пока нет магазина и разблокировки уровней, которые есть в оригинале-примере.
- Интерфейс проверен только сборкой и логикой; на реальном устройстве визуальную проверку ещё нужно сделать.
